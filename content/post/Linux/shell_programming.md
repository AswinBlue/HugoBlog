# Bash 셸 스크립트 프로그래밍 기초

## 셸 스크립트의 개념 및 작성 절차
셸 스크립트(Shell Script)는 리눅스 셸(Bash, Sh 등)에서 순차적으로 실행할 명령어들을 텍스트 파일에 나열하여 반복 작업을 자동화하는 프로그램입니다. 일반적으로 파일 확장자로 `.sh`를 부여합니다.

### 파일 생성과 실행 권한 (chmod)
새로 생성된 텍스트 파일은 기본 퍼미션에 실행 권한(`x`)이 포함되어 있지 않으므로, 스크립트를 독립 실행하려면 `chmod` 명령어로 실행 권한을 부여해야 합니다.

```bash
# 모든 사용자에게 실행 권한 부여
chmod +x myscript.sh

# 현재 디렉터리의 스크립트 직접 실행
./myscript.sh
```

### Shebang (샤뱅) 선언의 역할
스크립트 파일의 가장 첫 번째 줄에 위치하는 `#!/bin/bash` 구문을 **Shebang(샤뱅)**이라 부릅니다.
- 커널이 해당 스크립트를 해석할 인터프리터의 절대 경로를 지정합니다.
- 예: `#!/bin/bash`, `#!/bin/sh`, `#!/usr/bin/env python3`
- 샤뱅을 지정하지 않으면 현재 호출한 셸의 기본 서브셸로 스크립트를 해석하므로, 환경에 따라 문법 비호환 오류가 발생할 수 있습니다.

## 핵심 실행 옵션 및 디버깅 기법
Bash는 스크립트 실행의 안전성과 디버깅 편의를 위해 `set` 내장 명령어를 제공합니다.

### 오류 제어 (set -e)
- `set -e`: 스크립트 내에서 실행된 명령어가 0이 아닌 비정상 종료 코드(Error)를 반환하면 즉시 스크립트 전체를 중단합니다. 파이프라인이나 연속 배포 작업 시 오류 누적을 방지하는 필수 안전장치입니다.
- `set -o pipefail`: 파이프라인(`cmd1 | cmd2`) 중 어느 하나라도 실패할 경우 전체를 실패로 처리합니다.

### 명령어 추적 (set -x)
- `set -x`: 실행되는 각 명령어를 변수 치환이 완료된 상태로 표준 에러에 출력한 후 실행합니다. 스크립트의 실행 흐름과 조건문 분기를 시각적으로 추적할 수 있어 디버깅에 매우 유용합니다.
- `set +x`: 추적 모드를 다시 해제합니다.

```bash
#!/bin/bash
set -e
set -x

echo "안전 모드로 스크립트를 실행합니다."
```

## 텍스트 출력과 escape 처리 (echo)
- `echo`: 문자열을 표준 출력으로 인쇄합니다.
- `echo -e`: 백슬래시 이스케이프(`\`) 해석을 활성화합니다.
  - `\n`: 줄 바꿈 (개행)
  - `\t`: 수평 탭
  - `\e[...m`: 터미널 ANSI 색상 코드 적용

```bash
# 개행 문자를 반영한 출력 예시
echo -e "첫 번째 줄\n두 번째 줄\t(들여쓰기)"
```

## 특수 위치 매개변수 (Positional Parameters)
명령줄에서 스크립트를 실행할 때 전달된 인자(Arguments)는 셸 내장 특수 변수로 참조할 수 있습니다.

- `$0`: 실행 중인 스크립트 파일의 이름 (예: `./myscript.sh`)
- `$1`, `$2`, `$3` ...: 스크립트에 전달된 첫 번째, 두 번째, 세 번째 인자
- `${10}`: 10번째 이상의 인자는 중괄호로 감싸서 참조
- `$#`: 스크립트에 전달된 총 인자의 개수
- `$@`: 전달된 모든 인자의 목록 (따옴표로 감싸면 `"$1" "$2"` 형태로 각 인자를 독립된 단어로 보존)
- `$*`: 전달된 모든 인자를 단일 문자열로 결합
- `$?`: 가장 최근에 실행된 명령어의 종료 코드 (0: 성공, 1 이상: 오류)
- `$$`: 현재 셸 스크립트의 프로세스 ID (PID)

```bash
#!/bin/bash
# 실행 예시: ./test.sh apple banana cherry

echo "스크립트 이름: $0"
echo "전체 인자 개수: $#"
echo "첫 번째 인자: $1"
echo "두 번째 인자: $2"
echo "모든 인자 목록: $@"
```
